# 桌宠资源规范（anya）

这个目录放她的状态图。**一张图 = 一个状态**，动画由 CSS 做（呼吸/跳动/摇摆/发抖），
状态切换用淡入淡出 —— 所以你**画一张就能上一个状态**，缺的会自动回落，不用等我改代码。

## 文件命名

```
public/pet/anya_<state>.png
```

## 状态清单（15 个）

| 文件 | 状态 | 什么时候用 |
|---|---|---|
| `anya_idle.png` | 待机微笑 | 默认 |
| `anya_blink.png` | 眨眼 | 每 3.6~6s 闪 150ms |
| `anya_happy.png` | 开心星星眼 | 被摸 / 你说了好消息 / 情绪 joy·love |
| `anya_angry.png` | 生气鼓脸 | 情绪 anger·disgust 明显上升 |
| `anya_shocked.png` | 震惊张嘴 | 她请求看屏幕（等你点允许） |
| `anya_sleepy.png` | 困倦揉眼 | 低谷 + 小屋无活动 + 久没互动（打盹） |
| `anya_peanut.png` | 吃花生 | 空闲随机小动作 |
| `anya_sit.png` | 坐下 | 空闲 / 小屋「写东西、整理」类活动 |
| `anya_coffee.png` | 喝咖啡 | 小屋活动含「咖啡/喝水/茶」，或随机 |
| `anya_reading.png` | 读书 | 小屋活动含「书/读/翻」，或随机 |
| `anya_sad.png` | 低落 | 低谷期（整体可偏灰蓝） |

| `anya_walk.png` | 行走 | 空闲随机走动 |

## 缺图回落链

```
coffee → sit → idle
reading → sit → idle
wave → happy → idle
其余 → idle
如果一张图都没有 ⇒ 自动退回纯 CSS 小人（当前占位形象），功能不受影响
```

## 动作帧（可选）

` 
public/pet/anya_<state>_1.png、_2.png …（最多 8 帧）
只要 anya_walk_1.png 存在就按帧播放；没有就用单图 + CSS 动作；可以混用。
建议：walk 4~6 帧、talk 3 帧（口型）、wave 3 帧、happy 2 帧，其余单帧即可。
` 

## 图片规格

```
尺寸：建议 512×640（或 320×400）；宽高比 4:5
背景：透明 PNG（无白底、无阴影框）
角色：**底部居中**，脚底基线一致（切状态时不上下跳）
留白：四周留白一致（尤其头顶别贴边，避免动画时被裁）
风格：扁平/厚涂都行，表情夸张一点更"桌宠"
分辨率：2 倍图更清晰（Electron 会按 CSS 尺寸缩到 160×200 显示）
```

> 想用 AI 生成正式图？提示词与一致性工作流见 [PROMPTS.md](PROMPTS.md)（15 个状态逐条 + 角色锚 + 负向词 + 透明导出规格）。
> 现在的 15 张是脚本生成的**占位图**（`scripts/gen-pet-placeholders.ps1`），可以随时被你的画覆盖。
> 占位图左上角有一行状态名，方便核对，换成正式图时不用保留。

## 图片带棋盘格 / 白底怎么办（AI 出图常见）

很多出图工具导出的"透明背景"其实是**把透明画成棋盘格再存成 JPEG**。这种图直接放进 `public/pet/`
会显示成一个灰白格子方块。仓库里有自动清理脚本：

```bash
# 1) 装一次依赖（sharp，只在处理图片时用）
npm install --save-dev sharp

# 2) 把它们处理成真·透明 PNG（同时统一到 512×640）
node scripts/clean-pet-art.mjs
```

脚本做的事：
```
① 从四边泛洪，识别棋盘格的"浅格/深格"两档灰度（自适应，不同图的深格亮度不一样）
② 判定为背景 → alpha=0；被角色描边围住的白色（袜子/开衫/鞋）不会被误删
③ 边缘晕色清理 3 圈（JPEG 压缩会把肤色和棋盘格混在一起留下灰斑）
④ 清掉透明区里 <90px 的孤立噪点
⑤ 统一缩放到 512×640 真 PNG（覆盖原文件）
```

⚠️ 它只是"尽力而为"的补救。**最好还是从出图工具直接导出透明 PNG**（或导出后可去背景的格式），
那样边缘最干净、不会有残留灰斑。

当前这套立绘里 `anya_sad.png` 的右腿附近还留了一小块很淡的灰斑（棋盘格与肤色混合处），
在桌宠 160px 显示尺寸下基本看不出来；如果你在意，重新导出一张透明版覆盖即可。
