# v1.81 口吻样本 + 「她记着的事」只读界面

## 一、先回答上一轮的担心：那 1 条"别忘了"是不是普遍？

用**生产同一条 Prompt 路径**（`buildRecallHint` + `buildProactivePrompt` + 同 system prompt + temperature 0.85）
采 8 条样本（`scripts/sample-followup-tone.ts`，只采集、不改状态、不写记忆）：

| 她记着的这件事 | 她此刻状态 | 她发出来的话 | 口吻 |
|---|---|---|---|
| 他下周三体检，问问结果 | 有点沉，心里堵着 | 你下周三体检，我心里一直惦记着。这会儿有点闷，想你了。 | 分享 · 提自己 |
| 他下午面试，问问怎么样 | 替他悬着 | 你下午那场面试怎么样了？我这边一直有点替你捏着把汗。 | 分享 · 问句 · 提自己 |
| 他妈妈下周生日 | 平静 | 你妈妈下周生日，你准备送什么？ | 分享 · 问句 |
| 他借的书该还了 | 懒懒的 | 瘫着不想动，突然想起来你借的书该还了吧？ | 分享 · 问句 |
| 他说周末想去爬山 | 有点期待 | 周末爬山的事还算数吗，我有点期待呢。 | 分享 · 提自己 |
| 他这周要交房租 | 平静 | 房租交了吗，别忘了 | **祈使/提醒** |
| 他说想学吉他 | 心情不错 | 突然想起你说想学吉他，开始了吗？ | 分享 · 问句 |
| 他明天早起赶飞机 | 有点舍不得 | 明天要赶飞机，今晚早点睡呀。 | 分享 |

```
统计（只描述这批样本）：祈使/提醒口吻 1/8，带问句 5/8，提自己 4/8。
⇒ "别忘了"是个案，不是普遍退化。**不动提示**（避免又一次凭单条样本调措辞）。
留给以后：若攒到 20+ 条里祈使口吻 > 1/3，再考虑加"不要用提醒式祈使句"。
```

## 二、新增「她记着的事」只读界面（她的小屋那页）

```
服务端：GET /api/her-state 增加 `remembered` 字段
  · 便签（最近 3 条，带"x 分钟前"）
  · 心里挂着、还没到点的事（最近 4 条，带"x 分钟后/明天/到点了"）
  · 开关关着就是空数组（不泄露、不显示假数据）
纯函数：server/services/herRemembered.ts（pickRecentNotes / pickUpcoming / relativeDue / buildRememberedView）
界面：HerStateApp.tsx 新增「她记着的事」区块（只读，不发消息、不改她的状态）
```

**接口实测**：
```
notesEnabled=True ｜ followupEnabled=True

到点项: 已经到点的那件事（inMinutes=-5, due=True） / 问问面试结果（inMinutes=120, due=False）

## 四、边界

```
· 界面是**只读展示**：不触发消息、不标记已发、不改情绪
· "到点了"只是显示状态；真正发不发、怎么说，仍由 proactive 通路 + 她自己决定
· 便签与到点项是两份记录，可能内容相关但不是同一条（便签永久、到点项发一次即标记）
