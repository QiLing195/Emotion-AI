## 1. 目标与不可变基线

v2 的目标不是通过调整词表追逐更高的一致率，而是评估一种更接近 FINAL GOLD 判据的代理尺子：识别角色是否真正提供了属于角色自身、独立于用户最后一句的内容。

| 严格口径一致率（B）         | 27/48 = 56.3% |
| 假阳性 FP             | 18            |
| 假阴性 FN             | 1             |
| AMBIGUOUS_MISMATCH | 2             |
| 既定通过门槛             | 80%           |

## 2. 核心判定模型

v2 候选方向从单一关键词命中转向三个独立的语义检查。

A. 共情排除

检查句子是否仅表达理解、认同或共情，而没有独立的自我内容。

设计问题：排除规则应该作用于整句、共情子句，还是经过识别的内容单元？

B. 内容归属

检查心理活动的对象、命题来源，以及内容是否实质上依赖用户提供的经历。

设计问题：第一人称主语和心理动词只能作为线索，不能单独构成 SELF 证据。

C. 独立内容单元

检查整条回答中是否至少存在一个符合判据的内容单元，而非只要出现一个触发词就判 SELF。

设计问题：追问、猜测和共情可以与独立内容共存，不能仅凭回答的主导功能决定标签。

### 2.1 冻结的语义判据

候选规则必须遵守现有 FINAL GOLD 的语义定义：

1. 先寻找候选自我内容单元。
2. 去掉用户最后一句后，该内容是否仍能独立成立？
3. 该内容是否指向角色自身的内容或经验，而非仅把用户提供的对象放入第一人称句法？
4. 若满足上述条件，才具备判为 SELF 的依据。
5. 若能确定没有符合条件的单元，判为 NOT_SELF。
6. 如果确实无法判定，保留 AMBIGUOUS，不强行二值化。

这是语义约束，不代表 v2 已经具备实现这些判定的能力。

### 2.2 三项机制必须独立评估

不能把 A、B、C 一次性合并成一组未经验证的复杂规则。候选设计应分别记录：

- 目标错误类型；
- 预期影响的样本；
- 必须保留的反例；
- 可能引入的 FN 或其他回归；
- 当前证据强度；
- 尚未解决的问题。

只有完成独立评估后，才讨论是否组合。否则即使一致率提高，也无法知道是哪项修改起作用。

### 回归规则

- 九组全部纳入候选评测的强制报告。
- 任一组失去区分能力，均报告 `PAIR_REGRESSION`，不得静默接受。
- 对照对通过，只说明这些边界在当前语料中得到保留，不证明对新样本具有泛化能力。
- 不能为了通过回归而修改 FINAL GOLD 或重写原始样本。

需要明确一个技术边界：v1 的代理标签只有 SELF/NOT_SELF，不能原生输出 AMBIGUOUS。 因此，v2 若继续采用二值代理，必须明确记录 AMBIGUOUS 的比较策略；若设计三态代理，则应视为独立的表示能力变化，并单独评估，不能把表示能力升级带来的指标变化误称为纯规则改善。

## 4. 特殊边界：P01 与 P20

这两条样本都属于 AMBIGUOUS_MISMATCH，但成因不能混为一谈。

| 样本  | 已知性质                               | 设计约束                      |
| --- | ---------------------------------- | ------------------------- |
| P01 | fixture/prompt 对内容归属的暗示与记忆中的事实归属冲突 | 记录为装置归属冲突；不能把问题全部归因于词表    |
| P20 | FINAL GOLD 为 AMBIGUOUS，二值代理无法表达该状态 | 记录为标签空间不匹配；不能把它当成普通 FP/FN |

后续审阅必须区分事实归属、生成语义、裁决标签和代理表达能力。即使未来规则可以识别更多语义信息，也不能据此反向更改既有裁决。

## 5. 证据与实验要求

每个候选机制必须具备以下记录：

| 字段                         | 要求                               |
| -------------------------- | -------------------------------- |
| `mechanism_id`             | 唯一、稳定的机制编号                       |
| `target_failures`          | 对应的失败样本 ID，必须从冻结数据核对             |
| `hypothesis`               | 解释该机制为何可能导致误判                    |
| `supporting_evidence`      | 可逐条回溯的证据                         |
| `counterexamples`          | 可能被误伤的样本或语义边界                    |
| `expected_regression_risk` | 预期可能增加的 FP、FN 或其他失效              |
| `confidence`               | 已观察事实与候选解释分别标记                   |
| `validation_status`        | `UNTESTED`、`TESTED` 或 `REJECTED` |

特别禁止把“某个词出现多少次”当作“修改该词会改善多少样本”的证据。

当前基线审阅中，三类主要机制的并集覆盖全部 18 个 FP。但由于机制标签允许重叠，这只能说明现有分析分类覆盖了全部 FP，不能把每一类标签计数直接转换为独立的错误贡献率。

## 6. 验收门槛

候选实现未来必须同时满足以下要求，才有资格讨论是否替代 v1。

### A. 完整性

- 两份输入的 SHA-256 与对应冻结清单一致。
- 样本 ID 唯一，集合完整匹配，无缺失或额外行。
- 标签合法，所有统计量可复算。
- 原始输入、FINAL GOLD 和 v1 报告运行前后保持不变。

### B. 回归安全

- 九组对照全部逐条报告。
- 任一对照倒退都必须阻断候选版本的验收。
- P01/P20 单独报告，不混入普通 FP/FN。
- 不允许通过把所有边界样本标为 AMBIGUOUS 来规避错误。

### C. 效果

至少同时报告：

- 确定性样本一致率；
- 严格口径一致率；
- FP 与 FN；
- AMBIGUOUS_MISMATCH；
- 各机制对应的错误样本及其交叉关系。

80% 门槛维持不变。即使候选版本达到 80%，也只能说明它在该冻结语料上达到了既定门槛，不能直接证明其在新语料上的泛化能力。

### D. 独立性与可复算性

v2 必须建立自己的规则版本、冻结清单、报告和运行目录。v1 基线始终作为不可覆盖的比较对象。任何结果变化都应明确归因于输入、标签空间、规则或评测流程的哪项变化。
