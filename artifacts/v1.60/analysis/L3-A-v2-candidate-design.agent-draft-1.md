# 2. 三个主要失效机制（**相互独立的候选方向**）

> 三者都应作为**候选机制**记录。现有证据支持"值得研究"，**不能证明**某种具体修改一定有效。
> 三者不互斥，允许一条样本同时受多个机制影响。

## A. 共情排除（仅针对"裸句排除"这一具体缺陷）

| 项 | 内容 |
|---|---|
| 当前问题 | 冻结排除项为 `/^我(也)?(懂\|知道\|明白\|觉得你说得对)[。！]?$/` —— **只匹配裸形式**。一旦补上宾语（「我懂**那种感觉**。」「堵车那种感觉我懂，…」），排除即失效，句子凭 `SELF_ACT` 中的「懂」命中 |
| 涉及样本 | 事实：P07 P09 P12 P22 P28 的命中句均为"共情 + 补语"形态 |
| v2 设计要求 | 评估排除规则应基于**完整表达**还是**独立内容单元**；**不得**简单删除「懂/明白」——本语料中"SELF 侧仍有 3 条整条含『我懂』"，删词会牵动它们（**归属未逐句核对 ⇒ 未验证**） |
| 反例/风险 | 若只做"含『我懂』即排除"，会漏掉真正"先共情、后讲自己经历"的复合表达（本语料 48 条内 **0 条**此类样本 ⇒ 无样本支撑，也**不能**据此判断安全） |
| 状态 | 候选机制（证据充分的部分：裸句排除失效这一**机制**已由正则与命中句直接对照确认） |

## B. 内容归属（宾语 / 命题来源 / 用户指代依赖）

| 项 | 内容 |
|---|---|
| 当前问题 | 主语是「我」不代表内容属于角色。命中句的宾语常指向**用户的事件**：「记着**这件事**」「搬书**这事**」「**那层**油污」「**你这句话**」。`HIS` 只覆盖「你(之前\|上次\|那天\|说过\|说的\|提过\|提的\|讲过\|跟我说的\|想去)」，抓不到上述形态 |
| 涉及样本 | 事实：P11 P17 P18 P21 P24 P31 P35 P40 P45 P46（其中 P13 属"命题依赖"，见下） |
| v2 设计要求 | 增加对**宾语、命题来源、用户指代依赖**的判定要求（即"她说的这件事是谁的？"），而不是扩大指代词黑名单 |
| **硬边界** | 「这件事」**不天然**依赖用户 —— 角色也可指代自己独立经历的事；反之句中没有第二人称词也可能完全依赖用户 ⇒ **扩大黑名单无法解决本组**（此为基线审阅的核心结论） |
| 反例/风险 | 若把"含『这件事/这个』"一律排除 ⇒ 会误杀她自己经历的回指（本语料 SELF 侧 1 条含「这件事」、3 条含「这个」⇒ **未验证**，需逐条核对） |
| 状态 | 候选机制（部分样本证据充分，语义判定类样本仍属候选解释） |

## C. 单元独立性（整句关键词命中 → 独立内容单元）

| 项 | 内容 |
|---|---|
| 当前问题 | 现行实现是**整句**满足三个条件即算一个 self 单元：非疑问 ∧ 命中 `SELF_ACT` ∧ 不含 `HIS` ∧ 非纯附和。于是"整条以追问/猜测为主、句中另有一处第一人称动词"即可判 SELF（P26 等） |
| 涉及样本 | 事实：P26（追问为主）、P35（镜像 + 指代）等 |
| v2 设计要求 | 评估能否识别**独立内容单元**（该单元是否能脱离用户句成立），而不是对整句做关键词命中 |
| 反例/风险 | "独立性"目前无法用简单字符串表达；过早实现容易变成"更聪明的关键词"。若实现后**只降 FP 不降 FN**，须同时报告两者的净变化（见 §4 效果条件） |
| 状态 | 候选机制（机制方向明确，具体判据**未设计**、**未验证**） |

## 关于 FN（P34）：不并入上述三项

`P34` 是唯一 FN（gold=SELF，代理未命中）。两个**未分离的假说**：

```
H1 词表缺口：句中「我这两天也老想着这事」的"想着"不在 SELF_ACT（表内只有"想起"）
H2 句法缺口：`我[^。！？]{0,12}` 的窗口/动词位置要求，导致该句结构上无法命中
```

**不得**因为它是唯一 FN 就得出"加一个词即可修好"。若未来测试加词，必须同时报告它**新增命中的行**（本语料中 `想着` 出现在 3 条 SELF / 2 条 NOT_SELF ⇒ **净收益未知**）。

**关于 P01 / P20 的特别说明**

```
两者都是 AMBIGUOUS，但**原因不同**：
  P01 = 装置归属冲突（fixture 说书是他的、Prompt 说这是她自己的事）⇒ 属**装置缺陷**
  P20 = 语境不足以判定"那只猫是谁看到的"               ⇒ 属**语义不确定**
v2 不应把它们当成同一种语义问题；更**不能**通过强制二值分类来掩盖归属冲突。
```
