# v1.63 她的小屋 + 实时状态（第一刀）

> 用户的原话：**"她自己的事情有点作假，比如她怎么会打球、怎么会喝咖啡"**、
> **"需不需要给她一个活动的空间就像自己生活的小屋，角色就是一个小人有自己的生活"**、
> **"她的状态实时显示在屏幕上，我可以看到她的实时状态"**。

## 这一刀做了什么

```
① 她的小屋（server/services/herRoom.ts，ENABLE_HER_ROOM）
   白名单 10 种"一个人的室内活动"：煮咖啡/看窗外/听老歌/翻书/收拾桌面/随手画/浇绿萝/
   裹毯子发呆/伸懒腰开窗/写两笔又划掉
   · 当前活动是**持久化事实**（memories/her_room.json，跨轮/跨重启）
   · 每轮推进：未到时长保持；到期换下一个（低谷期 ×1.6 更黏）
   · 确定性挑选（同轮/同分钟可复现，不与当前重复）
   Prompt 只给一条事实：「此刻我在：<活动>」，并明令
   **小屋之外不许编工作/同事/运动/聚会/出差/朋友**
② 实时状态端点 GET /api/her-state（只读）
   返回：此刻情绪（激活态 top + delta）、低谷（active/established/turns/phase）、小屋活动与历史
③ 界面「她现在」（OS 应用，3s 轮询）
   大情绪 + 低谷标 + 小屋活动（"真实活动 · 非编造"）+ 之前的活动 tail
④ 默认开（本机 .env：ENABLE_HER_ROOM=true）
```

## 实测（5 轮真管道 + 默认 .env）

```
他问「你现在在做什么？」→ 她：「在听一首老歌，单曲循环，也没干别的。你今天那边怎么样？」
  ⇒ 回答与 /api/her-state 的活动**完全一致**（活动=在听一首老歌，单曲循环）
/api/her-state：roomEnabled=true ｜ 活动=在听一首老歌（0 分钟）｜ 情绪=disgust +0.183 ｜ 低谷=true/true turns=3
编造检查（打球/同事/聚会/出差/公司…）：**未出现**
小屋文件：memories/her_room.json ✓ 写入
```

界面证据：`artifacts/v1.63/her-state-ui-*.png`（"她现在"窗口：难过 +0.18 · 低谷已成段 2 轮 · 在听一首老歌）

## 仍未做（下一刀）

```
· "开心/尴尬等情绪下也能表达自己"：当前自状态表达许可仍只在「低谷 × 好消息」通路；
  要扩成多情绪（joy/pride/awkward/tired）需要新的片段族 + 预登记（避免又变成模板化）
· 小屋活动目前不进**动机层**（只说事实，不主动发起"我在做什么"）
· 小屋活动与时间线（timeline）尚未同源写入（两套记录，暂不互读）
```

## 回退

```
.env 里 ENABLE_HER_ROOM=false → 重启（/api/her-state 仍可用，活动为空；界面给提示）
删 memories/her_room.json → 小屋重置
代码默认值仍为 off（=== 'true'），仓库分发不受影响
```
