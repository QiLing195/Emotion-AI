# 项目错误案例台账

目的：把项目中真实发生的错误转换成可复查的对照案例，减少同类问题重复出现。修复错误时同步记录：错了什么、出错位置、为什么错、正确做法、如何发现及以后怎么检查。

**Skill 升级规则：**相同底层失误模式累计 3 次确认发生后，创建一个范围窄、可验证的专用 Skill；若已有对应 Skill，则更新它。阈值是项目默认值，可按实际重复率再调整。
