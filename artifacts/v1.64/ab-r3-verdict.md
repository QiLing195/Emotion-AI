## 机制问题定位（下一刀要改的是写法，不是参数）

```
症状：B 臂拿到的是"结构化多句模板"（状态：… / 原因可以带一句… / 最后一句要落回…），
     但她反而更不说了；A 臂是一句短许可（"可以说一句自己，也可以不说"）+ 例子，说了更多。
假说：**长而结构化的"许可"会被模型当作格式任务**（要同时满足状态/原因/落回三个要求），
     于是它把注意力放在"格式对不对"，而不是"要不要说一句自己"；
     而短许可把决定权交回给她，她反而敢说。
对应改法（下一刀）：
   ① 统一接口的 permit 缩成**一两句**："你可以说一句自己（也可以不说）；想说几句都行，不用按格式"。
   ② 多句能力靠"允许"而不是"模板"——不给"状态：/原因：/落回："的骨架。
   ③ 落地后**再跑一次**同样判据（第三次已证：结构模板无效）。
```
