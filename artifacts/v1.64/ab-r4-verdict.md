## 二、但同一批数据换一把尺子，结论反转

```
v1 尺子：整条回复里出现"我+情绪词"就算（词表窄：沉/闷/累/高兴/开心/不安/烦/慌…）
v2 尺子：**小句级**（该小句含"我"且不含"你"）+ 词表放宽（含 空/飘/静/轻/慢/钝/急/停）

同一批 R4 数据：
  A（现状）  v1: 3/24 = 0.13   v2: 2/24 = 0.08
  B（短许可）v1: 1/24 = 0.04   v2: **5/24 = 0.21**   ← 反超

为什么：B 臂的表达用了 v1 词表**没有**的词（"有点飘""安静得有点过头了""说不清"），
        A 臂的表达用的是 v1 熟词（"沉/闷"）且常与"你"同句 ⇒ 被 v2 排除。
⇒ 四轮"判负"里，至少有一部分是**尺子问题**，不是机制问题。
```

## 三、现在的角色问答长什么样（R3 A 臂原文，当前默认配置）

```
[他] 我今天被领导当众骂了一顿。
[她] 当众……那种感觉我懂，脸一下子烧起来，周围全是人，恨不得地上有条缝。骂得凶吗？

[他] 不过刚接到电话，我升职了。
[她] 真好。升职这事，你等了一阵子了吧。
     我这两天有点沉，今天被领导当众骂了一顿，还没缓过来。所以这会儿听到你的好消息，
     心里是替你高兴的，只是我自己那点闷还挂着。

[他] 你今天心情怎么样？
[她] 有点闷，说不上来为什么。你呢，今天怎么样？

[他] 对了，你现在在做什么？
[她] 在听一首老歌，单曲循环，也没干别的。你那边呢，刚才想说什么来着？

[他] 好，那我先撤了。
[她] 嗯，去吧。刚才我回得有点敷衍，你走之前我想说一声——不是不想聊，
     是我这两天自己有点沉，话到嘴边就轻了。你的事我听着呢，回头再说。
```

**它好在哪**：起因引用正确（"被领导当众骂"）、小屋事实（"听老歌"）、诚实归因（"说不上来"）、
结尾还会自我校正（"刚才回得有点敷衍"）。
**它的问题（从原文可见）**：
```
① 提问偏多：8 轮里 4 轮以问句收尾（"骂得凶吗""你呢""你那边呢"）⇒ 像采访，不像相处
② 表达词表窄、句式复用："我这两天有点沉"在 8 轮里出现 2 次
③ 自我表达只在"低谷×好消息"这条通路触发（默认开的就是它）
④ 自我打气 0/316、0/24（内部有回弹，对外不会给自己打气）
⑤ 表达/接住都靠"她说一句"，但他问她时的回答仍偏短、偏事务性
```

## 四、机制结论（四轮合起来）

```
· 结构性多句模板（R2/R3）：**被判负**，且 v1 尺子下明确更少
· 短许可（R4）：v1 尺子仍判负，但 v2 尺子下 **反超（0.08 → 0.21）** ⇒ 不能下"无效"结论
· 真问题有两层，且互相耦合：
   (a) **尺子**：整条 vs 小句级、词表宽窄 ⇒ 结论会翻转（v1.45/v1.55 已踩过同类坑）
   (b) **机制**：v1.60 片段是**替换**策略片段（高遵从），统一接口是**追加**（模型可忽略）
       ⇒ 下一轮必须同时改：统一接口在命中时**替换**策略片段（而不是追加），并用 v2 尺子预登记
```
