## 关键发现（比结论更重要）：**判据与机制结构性冲突**

```
统一接口带**预算门**：每 4 轮最多表达一次。
6 轮剧本 ⇒ 最多 1~2 次表达 ⇒ 表达率上限 ≈ 1.5/6 = **0.25**；
而 A 臂的 v1.60 片段没有预算（只要"低谷×好消息"就替换），所以 A 的 0.17 不是同一把尺子。
⇒ 判据①（B ≥ A+0.15）在预算机制下**结构上几乎无法满足** ——
   这不是"机制无效"，而是**实验设计把机制的上限当成了失败**。
```

## 定性证据：多句表达确实在发生（B 臂原文）

```
[他] 心里堵得慌。
[她] 堵得慌的时候，我一般会先把手里的事停下来。刚才那首歌我按了暂停，现在屋里很安静。
     你愿意说说，是哪种堵吗？…          ← 状态 + 小屋事实 + 落回他（多句）

[他] 你今天好像有点不一样。
[她] 你倒是挺敏锐的。今天心里有点空，说不上来为什么，就那种……歌放着，人却飘着的感觉。
     不过你说"不一样"——是从哪儿看出来的？   ← 状态 + 诚实归因（说不上来）+ 落回他
```

## 因此：保持默认关 + 下一刀的两处修正

```
① 指标要按**机制可达域**设计：改成"**许可轮内的表达率**"（permitted-turn rate），
   或把预算调大做一次实验（但那是改机制，需要单独预登记）
② 预算本身值得重新审视：4 轮可能偏严（她可能"想说说不出"）；
   候选：预算 4→3，且"他明确问到她"时允许突破预算一次（问必答）
③ 统一接口保留（结构更干净：一个出口 + 多句 + 接地 + 轮换），但没有证据前不默认开
```
