# v1.64 统一情绪表达接口（第一刀）

> 用户问：**"把所用情绪都一个接口，然后可以让他们表达出来可行吗？"**
> 答：可行；但必须带**三重约束**，否则会变成"她一直表演情绪"。

## 做了什么

```
src/lib/emotionExpression.ts（ENABLE_EMOTION_EXPRESSION，默认关）
· 把九情收敛成 8 个"说得出口"的类别：joy / love / sad / fear / anger / disgust / tired / awkward
  （greed / calm 不映射：一个是要，一个是静息，都不适合"表达情绪"）
· 每类 3 个变体，短句、第一人称、不夸张、不索要安慰、结尾落回他
· 三重约束：
  ① 只表达**被激起**的（delta > 0.05，且主导要领先第二名 ≥0.05；低谷期悲伤优先）
  ② **预算**：每 4 轮最多一次（防"说难过→他哄→更爱说难过"的表演回路）
  ③ **接地**：原因只能引他的话（时间线引文）；没有就明令"说不上来，不要为了给原因编事"
· 只读状态、不写回（不改变情绪动力学）
· 接线：aiCoordinator 在策略片段之后**追加**（不替换安全策略），带 try/catch
```

## 实测（6 轮真管道，开关临时打开）

```
[EmotionExpr] 触发 1 次（sad +0.16）—— 预算门在起作用（每 4 轮一次）
回复痕迹（她自己的状态，不是他的）：
  [4]「我这两天有点沉，听到你这个消息，心里还是亮了一下。」
  [5]「只是我今天心里有点闷，像有东西卡着，说不清。」   ← 允许"说不清"，没有编原因
  [3]「我这边正放着一首老歌，单曲循环好几遍了…」        ← 小屋事实，自然出现
编造检查（打球/同事/聚会/出差/公司）：未出现
```

## 为什么"最初的涌现"与现在不冲突（回答用户的第二个问题）

```
涌现（v1.7/v1.8：传染/内在/心情/反刍）= **状态怎么产生**（输入侧）
表达通道（v1.60 自状态 / v1.64 统一接口） = **状态怎么被说出**（输出侧）
只要表达只读不写，两者不冲突；四条真实风险及本刀的应对：
① 自发情绪没有外部原因 ⇒ 允许"说不上来"（模板内置）
② 反刍钝化/心情衰减让情绪长期低于死区 ⇒ 表达会长期静息（这是"她没在演"的证据，不是 bug）
③ 观察者回路（她表达→他哄→强化）⇒ 预算 4 轮 + 只读不写回
④ 观测层（timeline/her_room）只记事实、不进动力学 ⇒ 无因果冲突
```
