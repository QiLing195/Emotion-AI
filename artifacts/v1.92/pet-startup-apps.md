# v1.92：桌宠启动时顺带打开常用程序（飞鸟加速）

> 用户："开机打开飞鸟加速" → 选了「二丫桌宠启动时帮你打开飞鸟加速」。

## 一、结论：改成"桌宠启动时打开"，撤销了开机自启

```
之前那版：把快捷方式放进 Windows「启动」文件夹 ⇒ 开机就启动（已撤销，避免两处重复启动）
现在这版：**桌宠起来的时候** 才打开飞鸟加速，3 秒延迟，关掉桌宠不会关它
```

## 二、怎么做的

```
配置文件 desktop/pet-startup.json（改这个文件就行，不用动代码）
{
  "delayMs": 3000,          // 桌宠起来后等几秒再开（避免抢开机资源）
  "skipIfRunning": true,    // 已经在跑就不重复开
  "apps": [
    { "name": "飞鸟加速", "path": "E:\\Program Files (x86)\\feiniao\\飞鸟加速.exe" }
  ]
}
桌宠主进程在窗口建好后调用 openStartupApps()：
  ① 读配置 ② 逐项：文件不存在 ⇒ 跳过并写日志；已在运行 ⇒ 跳过并写日志
  ③ 否则 detached spawn 打开（失败回退 shell.openPath，可能触发 UAC）
```

## 三、顺带发现：你桌面那个「飞鸟加速」图标是坏的

```
桌面快捷方式 → E:\Program Files (x86)\飞鸟\飞鸟加速.exe     ❌ 目录不存在（旧中文目录）
真实安装     → E:\Program Files (x86)\feiniao\飞鸟加速.exe   ✓
```
启动项指向的是**真实路径**（不是坏快捷方式），所以能正常打开。
桌面图标的修复没动（那是用户自己的图标）——需要的话一句话就能修。

## 四、验证（用记事本替身验证机制，避免反复启停你的加速器）

你的飞鸟加速进程全程没动（仍在运行）。
