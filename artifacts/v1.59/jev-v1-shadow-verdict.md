### §2.1 "状态为空"问题的解决情况（[直接]，40 条账本可核）

```
修复前（首跑 run1）：valence=0、activated={}、low_period=null、rumination=**null**  ⇒ 40/40 全空
修复后（这批 40 条）：rumination 有值 **40/40**；activated 为空 **4/40** —— 全部是四段对话的**第 1 轮**
                    （v=0、无任何情绪被激起 = 她的**静息**，不是"没状态"）
                    low_period 为真 5/40（短对话 + 中性剧本 ⇒ 符合设计：需 ≥2 次落定）
```

```
① 读错字段（真 bug，已修）：valence→taiji.valence ｜ 低谷→顶层 lowPeriod ｜ 反刍→emotion/streak ｜ activated→activationOf
② 时标（设计如此，不是 bug）：low_period 需 ≥2 次落定、rumination 需 ≥3 轮 ⇒ 短对话天然为空；
   替代信号是 activated（每轮都有），已接上
③ 仍可改进（小）：记录里"静息"与"没状态"目前长得一样 ⇒ 建议透传 activationOf 的 resting/note
```

## §3 关键发现（按证据等级）

```
[直接] v0 的两个"非 jev 问题"：
  · 输入装配读错字段（见 §2.1）⇒ her_state 全空
  · 激活态完全没接 ⇒ 短对话下状态必然空白 ⇒ jev 镜像/编造她的情绪（首跑 2 次）
[直接] 三个实现/定义缺陷（真实样本抓出，均有 commit）：
  · 护栏方向反了（activated 正=被激起，写成 ≤ −0.05）⇒ 误杀真证据（第 3 轮 disgust +0.117）
  · 超时 1200ms 贴着实测 p90 1149/max 1714 ⇒ 20 条里 1 次超时；改 2000ms 后 0 超时
  · 冲突类用 0.05（激活死区）判"她低落" ⇒ 一组她根本不低的剧本被 9/10 判成冲突轮；
    改用项目既有"真沉"语义 0.12（LOW_PERIOD_SINK 同源）后，冲突/非冲突由 32/8 变 19/21
[直接] v0 退化成"永远 wait"（wait 18/19）⇒ prompt 漏了人设裁定「主动性降低，但不是没有」
       且未定义 share/ask/wait；v1 补上后人设方向回来（share 17 / ask 9 / wait 14）
[分析] 冲突族的分歧方向一致指向"从追问/沉默 → 端出她自己的事"，与人设裁定同向
[待验证] ①真实对话分布下是否仍成立；②shadow→on 是否值得；③语义增益（本记录不涉及）
```

## §4 边界（不可外推）

```
· 剧本是**人工设计**、非随机抽样；40 条来自 4 个会话（每会话 10 轮），非独立同分布
· ②量的是**意图**（wouldOverride），不是生效行为（shadow 永不生效）
· ④只证"权限闸门按当前定义工作"，不证 jev 决策质量
· 有一条口径不一致（jev-fixed-c-298：她不沉，仅 blip 级 +0.05 给出 HER_LOW_HE_RISES，
  被**宽松护栏**放行）。若把护栏收紧到"必须真沉 0.12"，该条会被拒 ⇒ ③ 变 1/20=5% ⇒ 判定翻 FAIL。
  ⇒ 当前"通过"依赖"宽松护栏 + 严格冲突类"这个组合；改口径须重跑并接受可能的 FAIL。
· n=40 仍属小样本；①/④ 的代理判据较粗
```
