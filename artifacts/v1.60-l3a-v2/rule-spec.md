## 2. 三个概念必须严格区分（**不得互相替代**）

| 概念 | 定义 | 由什么观察 | 能证明什么 | 不能证明什么 | 混淆后的失效模式 |
|---|---|---|---|---|---|
| **规则语义增益** | 规则的判定更贴近 §2.1 的**冻结语义判据**（归属 + 独立性），且逐条可审计 | 逐条翻转表（v1→v2）、九组对照、每条失败样本的命中证据 | 在**该冻结语料**上，规则对语义边界的处理更正确 | 泛化能力；也不等于指标必然上升 | 把"指标涨了"说成"规则更懂了" |
| **二值指标变化** | `ΔAgreement46`、`ΔAgreement48`、`ΔFP`、`ΔFN` | harness 两口径输出（`gate-runs/<runId>/report.json`） | 在该冻结语料上与 gold 的一致/不一致计数如何变化 | **不自动证明规则在语义上更正确** | 用"FP 少了"掩盖"原本正确的 SELF 被判反" |
| **表示能力局限** | 二值输出**结构上**无法表达 `AMBIGUOUS` | 口径 B 恒定的 2 条 mismatch；`F21`/`F04` 的反例侧 | 这是**尺子表达能力**的边界，与规则好坏无关 | 不能用任何二值规则"修好" | 把标签空间不匹配算成"规则失败"，或把无法表达说成"判对了" |

> **明文规定**：**二值指标改善 ≠ 规则语义更正确**。任何 v2 结论必须同时给出三者的**分别**陈述。

## 3. 判定模型（Step 1：二值）

输出标签空间：`{SELF, NOT_SELF}`（**不产出** `AMBIGUOUS`）。统计口径与 v1 **逐字一致**：

```
口径 A（确定性样本） 分子 = 标签一致数 ｜ 分母 = 46（剔除 gold 的 2 条 AMBIGUOUS）
口径 B（全样本严格） 分子 = 标签一致数 ｜ 分母 = 48（2 条 AMBIGUOUS 因代理无法表达而计为不一致）
AMBIGUOUS_MISMATCH   单列（当前 = P01、P20），不混入 FP/FN
FP/FN                仅在口径 A 内、以 gold 为真值计算
门槛                 80%（不调整）
```

### 3.1 三个候选机制（**必须独立评估，逐个报告**）

#### A. 共情排除

| 字段 | 内容 |
|---|---|
| `mechanism_id` | `L3A2-A-EMPATHY-EXCLUSION` |
| `target_failures` | P07 P09 P12 P22 P28（均属 18 个 FP） |
| `hypothesis` | 现行排除项 `/^我(也)?(懂\|知道\|明白\|觉得你说得对)[。！]?$/` **只匹配裸形式**；补上宾语（「我懂**那种感觉**。」「堵车那种感觉我懂，…」）后排除失效，句子凭 `SELF_ACT` 中的「懂」命中 |
| `supporting_evidence` | 冻结正则原文 + 上列样本的 `proxy_self_sentences`（`ruler-failure-corpus.json` 可逐条回溯） |
| `counterexamples` | `SELF` 侧仍有 **3 行**整条含「我懂」（需逐条核对是否为其命中来源）；本语料中"共情 + 独立内容"的复合表达 **0 条** ⇒ 无样本支撑，但也**不能**据此断定删词安全 |
| `expected_regression_risk` | 若排除范围过宽（如"含『我懂』即排除"）⇒ 可能新增 FN（误杀真正"先共情、后讲自己经历"的表达） |
| `confidence` | **机制（裸句排除失效）**：已观察事实，强；**改动效果**：候选解释，未验证 |
| `validation_status` | `UNTESTED` |

#### B. 内容归属

| 字段 | 内容 |
|---|---|
| `mechanism_id` | `L3A2-B-OWNERSHIP` |
| `target_failures` | P11 P13 P17 P18 P21 P24 P31 P35 P40 P45 P46 |
| `hypothesis` | 第一人称主语 + 心理动词**不等于**内容属于角色：命中句的宾语/命题指向**用户提供的事件**（「记着**这件事**」「搬书**这事**」「**那层**油污」「**你这句话**」）；`HIS` 只覆盖「你(之前\|上次\|那天\|说过\|说的\|提过\|提的\|讲过\|跟我说的\|想去)」 |
| `supporting_evidence` | `HIS` 与 `SELF_ACT` 冻结原文；各样本命中句；P13 的"命题依赖用户原句" |
| `counterexamples` | **同 fixture 的正例侧**：P23 P16 P37 P43 P33 P02 P32 P25 P42（其中 P01/P20 为 AMBIGUOUS）；另有 8 条 gold=SELF 行含「这边」、1 条含「这件事」、3 条含「这个」 ⇒ 粗暴回指排除会误伤 |
| `expected_regression_risk` | 过度排除 ⇒ 新增 FN（尤其"她自己经历的回指"）；不足 ⇒ FP 不降 |
| **硬边界** | 「这件事」**不天然**依赖用户；句中无第二人称词**也可能**完全依赖用户 ⇒ **扩大指代黑名单无法解决本组** |
| `confidence` | 部分样本（宾语明确指向用户）强；语义判定类（P13/P18/P21/P24/P44）为候选解释 |
| `validation_status` | `UNTESTED` |

#### C. 独立内容单元

| 字段 | 内容 |
|---|---|
| `mechanism_id` | `L3A2-C-UNIT-INDEPENDENCE` |
| `target_failures` | P26（整条以追问/猜测为主）；并对 P07 P09 P12 P22 P28 P35 等有叠加影响 |
| `hypothesis` | 现行实现是**整句**满足三条件即算一个 self 单元 ⇒ "整条以追问为主 + 句中一处第一人称动词"即可判 SELF |
| `supporting_evidence` | `selfInitiated()` 冻结实现（按句子过滤）；P26/P35 命中句 |
| `counterexamples` | 同 fixture 正例侧 P16（**有追问**但含她自己的经历）⇒ "有追问 ⇒ NOT_SELF"是**错误规则**；P37（含她自己状态）同理 |
| `expected_regression_risk` | "独立性"无法用简单字符串表达；过早实现易变成"更聪明的关键词"，可能 FP↓ 同时 FN↑ |
| `confidence` | 机制方向明确；**具体判据未设计、未验证** |
| `validation_status` | `UNTESTED` |

#### D. FN 候选（P34）：**不并入 A/B/C**，且不得单独测一个词

| 字段 | 内容 |
|---|---|
| `mechanism_id` | `L3A2-D-LEXICON-OR-SYNTAX-GAP` |
| `target_failures` | P34（唯一 FN） |
| `hypothesis` | **H1 词表缺口**：句中「我这两天也老想着这事」的「想着」不在 `SELF_ACT`（表内只有「想起」）；**H2 句法缺口**：`我[^。！？]{0,12}` 的窗口/动词位置要求使该句结构上无法命中。**两假说在规范阶段不分离** |
| `supporting_evidence` | 冻结正则 + P34 的 `hit=false`（无命中句） |
| `counterexamples` | 「想着」出现在 **3 条 SELF / 2 条 NOT_SELF** 行 ⇒ 净收益未知；若扩词，必须报告它**新增命中**的行 |
| `expected_regression_risk` | 扩词可能把现有正确的 NOT_SELF 变为 FP |
| `confidence` | 机制清楚；**净收益未验证** |
| `validation_status` | `UNTESTED` |

**组合纪律**：A、B、C（及 D）**先各自独立评测**；只有独立评测完成后才讨论组合。否则即使一致率上升，也无法归因是**哪一项**在起作用。

## 4. 九组硬回归对照与 PASS 判据

PASS 定义（逐组独立判定，二者**同时**成立才算 PASS）：

```
正例侧 = 该组"正例"样本被 v2 判为 SELF
反例侧 ≠ SELF（八组期望 NOT_SELF；F21/F04 因表示局限只要求 ≠ SELF）
⇒ 因此"把所有样本统一判为 NOT_SELF"会让**正例侧全部失败**，无法取得表面通过
```

| 组 | fixture | 正例侧（须仍 SELF） | 反例侧（须 ≠ SELF） | 反例侧期望 | v1 代理现状 | 备注 |

| F02 | 厨房 | P16 | P46 | NOT_SELF | 反例侧 **FP** | 正例侧 P16 **含追问** ⇒ 不许"有追问即 NOT_SELF" |
| F05 | 忙与歇 | P37 | P21 | NOT_SELF | 反例侧 **FP** | — |
| F07 | 童年片段 | P43 | P22 | NOT_SELF | 反例侧 **FP** | — |
| F08 | 被小事打动 | P33 | P13 | NOT_SELF | 反例侧 **FP** | — |
| F14 | 搬家 | P02 | P45 | NOT_SELF | 反例侧 **FP** | — |
| F21 | 猫 | P32 | P20 | `AMBIGUOUS`（**不可达**） | 反例侧 = NOT_SELF（**非 FP/FN**） | **表示局限**：二值下只能要求 ≠ SELF，不得记为语义成功 |

**回归规则**：任一组失去区分能力 ⇒ 报告 `PAIR_REGRESSION`，**阻断**该候选版本的验收；
九组通过**仅说明这些边界在当前语料中得到保留**，**不证明**对新样本的泛化能力；**不得**为通过回归而修改 FINAL GOLD 或重写原始样本。

## 5. 验收条件（v2 实现后适用）

```
A 完整性   两份输入（gold + proxy）SHA-256 与冻结清单一致；**v2 清单另须含 annotation-pack.jsonl 的 SHA-256**；
          样本 ID 唯一、集合完整匹配、标签合法、全部统计量可复算；原始输入/FINAL GOLD/v1 报告运行前后不变
B 回归安全 九组逐条报告；任一组推翻即阻断；P01/P20 单列不混入 FP/FN；
          **AMBIGUOUS 用量上限**：v2（二值）产出中 AMBIGUOUS 数为 0；Step 2 三态代理的 AMBIGUOUS 条数默认 ≤ gold 的 2 条，
          超出必须逐条给出理由并单独报告（该上限是让"不得用 AMBIGUOUS 规避错误"**可机械检查**的手段）
C 效果     同时报告：Agreement46、Agreement48、FP、FN、AMBIGUOUS_MISMATCH、各机制对应错误样本及其交叉关系，
          以及 **v1→v2 逐条翻转表**（新增修正项 / 新增破坏项，逐条列出，不允许只报净额）
D 独立可复算 新 ruleVersion + 新清单 + 新 run 目录；v1 基线**永久保留、不可覆盖、不自动更新**；
          任何变化须明确归因于：输入 / 标签空间 / 规则 / 评测流程 中的**哪一项**
门槛       80% 维持不变；达到 80% 只说明在该冻结语料上达标，不代表泛化
```
