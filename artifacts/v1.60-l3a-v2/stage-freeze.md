## 3. 两条不可让步的原则

### 原则一：P0 必须是逐字节重放，且零漂移

```
[ ] 用 v1 规则对 annotation-pack.jsonl 重算 ⇒ 与 regex-proxy.jsonl **逐字节相同**
      （SHA-256 9f53101b327abe7f39143652f71918dd965d7136c42e718d17e18c15c060ef5f）
[ ] harness 以 v1 清单重跑 ⇒ **ASSERTIONS 18/18 PASS**
[ ] 与 v1 基线**零漂移**：A 27/46 ｜ B 27/48 ｜ FP 18 ｜ FN 1 ｜ AMBIGUOUS_MISMATCH 2 ｜ gatePassed=false
[ ] v1 全部冻结物（pack / gold / proxy / gate-baseline.json / gate1-agreement.* / gate-runs/**）运行前后哈希 + mtime 不变
任一不满足 ⇒ **停止**，不得进入 P1。
```

### 原则二：P1 不得仅凭数字宣布语义改善

```
即使 P1 提高一致率，也必须**同时**审查并报告：
[ ] **具体修正项**（v1 错 → v2 对，逐条 pack_id + 证据）
[ ] **具体破坏项**（v1 对 → v2 错，逐条 pack_id + 证据）—— 不允许只报净额
[ ] **九组回归对照**逐组两侧结果（正例侧 == SELF ∧ 反例侧 != SELF）
[ ] **三概念分别陈述**：规则语义增益 / 二值指标变化 / 表示能力局限
[ ] F21 / F04 的 AMBIGUOUS 侧仍记为**表示局限**，不计为语义成功
```

### 附带边界：机械完整性 ≠ 语义正确

```
冻结文件完整性通过（哈希一致、断言全绿、零漂移）只能证明**实验输入与流程符合约定**，
**不能证明代理规则的语义正确**。后者必须依靠**具体样本、反例与独立的验收标准**。
⇒ P0 通过只能表述为"工具链等价"，**不得**表述为"规则更正确"。
⇒ harness 全绿同理：它证明流程自洽，不证明评价标准本身正确。
```
