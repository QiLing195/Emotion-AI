上下文 · RAG · LLM：她回一句话时到底发生了什么道·AI 女友 / v1.98 架构图

一条消息进来 → 感知与情绪动力学 → 上下文装配（含 RAG 召回）→ LLM 生成 → 校验与写回。颜色：规则/确定性检索模型

1输入

  • 他这句话（/api/chat 或语音唤醒后转写）
  • 前台窗口活动（20s 采样，标题+进程，敏感已脱敏）只读
  • 她的小屋状态 / 上次互动时间 / 关系阶段
▶

2感知与情绪

  • 情感分析 LLM 或本地规则 → 九情事件 + 他的情绪
  • 活动理解 规则 12 类 →「他像是在找工作」+ vague 标记
  • 情绪动力学：9 情 / 太极 / 心情层 / 反刍 / 评价层 / 内在事件（含 activity_concern）
▶

3上下文装配（Prompt 组装）

  • ① 人格底座　② 自我叙事（长期记忆）
  • ③ 记忆召回 = RAG（见右侧细节）　④ 动机层：她此刻想说什么
  • ⑤ 策略片段（7 种）　⑥ 活动理解一行 【我看到的】…
  • ⑦ 她的状态（情绪/小屋）　⑧ 边界与禁令
▶

4LLM 生成

  • aiProvider（可带 function calling，有界 2 轮）
  • 工具：recall_memory / read_my_activity / look_at_my_screen / MCP 只读…
  • 产出：她的话（短句、口语、带自己状态）
▶

5校验与输出

  • 记忆接地校验：「你说过…」必须能在她知识里落地，否则重写/删句 防编造
  • 复读尺 / 清洗 / 长度 → 气泡（可选语音）
  • 写回：情景记忆 + 图谱节点 + 情感时间线 + 学习账本

RAG（检索增强）在这里具体做什么

Query他这句话 ⊕ 当前情境（情绪 / 关系阶段 / 话题锚点 / 时间） 四路召回① 情景记忆相似度　② 记忆图谱 BFS 激活扩散　③ 统一四源召回　④ 主动回忆（动机闸门选中） 打分词面相关 × 情绪签名 × 时间衰减(艾宾浩斯) × 关系可见性 门控敏感度×关系阶段（memoryVisibility）／治理状态（verified/rolled_back）／遗忘曲线归档 注入预算内 top-k 片段 + 引用提示；不塞原始日志，只塞「能被引用的事实」 兜底生成后再过接地校验：没依据的断言重写或删除 规则

人格/叙事/禁令是「她是谁、不能做什么」；RAG 是「她记得什么」；动机/策略是「这轮怎么说」；活动理解/状态是「此刻」。

旁路：她主动关心（不经他开口）

  • 每 60s：活动理解 → 是否「关心类」（找工作/开会/学习/写代码）且证据不 vague
  • 门槛：持续 ≥20 分钟（低谷 40）→ 冷却 90 分钟（低谷 180）→ 每天 ≤2 次（低谷 1）→ 时间窗 8:00–23:00
  • 通过 → LLM 生成 ≤40 字（带「上次你问过…这次问结果」的记忆）
  • 入队 → 桌宠气泡；落盘 memories/activity_care.json，界面「她心里记着的你的事」

为什么不是「把记忆全塞给模型」

  • 禁止模型自己编记忆：RAG 只给可引用片段；生成后仍有接地校验
  • 规则与模型分工：情绪动力学 / 活动理解 / 门槛 / 校验 = 规则（可解释、可测）；措辞与共情 = 模型
  • 预算意识：动机放在 Prompt 末尾（注意力最高处）；记忆按需召回而不是全量

一句话：规则负责「她此刻是谁、记得什么够格、什么不能说」，模型负责「怎么把这件事说成人话」； RAG 把「她记得的」变成少数可引用事实，生成后再用规则查一遍有没有编。主动关心是同一套上下文装配的旁路（触发源从"他说话"换成"他的窗口"）。
