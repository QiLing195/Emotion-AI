# v1.73 工具扩容 + 多轮连续 A/B 装置（重要：此前的 harness 是失真的）

> 用户指出：**"对于测试对话，可以进行连续多轮测试，而不是一问一答"** —— 这是对的，也是本刀最重要的修正。

## 一、装置问题（为什么之前所有 A/B 都有一层失真）

```
此前 harness：每轮都发 `recentMessages: []`
  ⇒ 她永远看不到上一轮（只能靠记忆/状态里的痕迹推测）
  ⇒ 与真实使用（聊天窗口带历史）不是同一个装置

本刀：scripts/ab-runner.ts
  · 每轮把 recentMessages **累积成真实对话历史**再发
  · 每个 arm 独立进程 + 独立端口；记录每轮耗时/回复；落盘 JSON；打印对比表
  · env 显式指定（**踩过的坑**：A 臂曾继承 .env 的开关 ⇒ 两臂其实都开着；现在 A 显式写 false）
```

## 二、多轮连续 A/B（8 轮连续对话 × 2 次/臂，A=工具关 / B=工具开）

| 指标 | A（关） | B（开） |
|---|---|---|
| 平均回复长度 | 32 字 | **51 字** |
| 平均单轮耗时 | 3.7s | 4.2s |
| 以问句结尾 | 10 | **5** |
| "工具腔"（工具/查询/数据库…） | 0 | 0 |

**原文对照（第 5~7 轮）**：

```
[他] 我们最近都聊了什么？
[A]  说实话，我记不太清了。你问这句，是想听我再说一遍…      ← 空
[B]  让我想想。你被领导当众骂，然后说心里堵得慌，接着就接到电话说升职了。这一段挺折腾的。
     再往前……我记不太清了。                                  ← 有具体、且承认边界

[他] 对了，你还记得我上次说面试那事吗？
[A]  记得，你说要去面试。后来呢，成了吗？                     ← 可能编（没有这条记忆）
[B]  面试这件事，我记不太清具体说过什么了。你那时候说的是哪一场？  ← 如实说记不清
```

## 三、工具扩容（本刀新增两个只读工具）

```
recall_memory(query, limit) —— 按话题检索记忆（复用 unifiedMemory.recall）
   没查到 ⇒ 如实返回"记忆里没检索到…"（不许编；单测钉住）
time_now() —— 本地日期/时间/星期（消灭"今天/明天"说错）
⇒ 工具总数 4 个：check_my_state / recall_memory / time_now / recall_recent_events
护栏不变：≤2 轮、≤4 次调用、逐条 trace、失败回灌不抛错
```
