# v1.84 桌宠：透明窗口 + 动作系统

> 用户反馈："这个桌宠不要黑框，变成透明的，然后桌宠设计一下动作"。

## 一、黑框的根因与修法

```
根因：不是 Electron 窗口不透明，而是**网页底色**——src/index.css 里 `body { background: #0b0d17 }`
      ⇒ /pet 页面整个窗口被涂成深色，看起来就是一个黑框。

修法（三处）：
  ① index.css 加 `html.pet-mode` 规则：html/body/#root 全部 transparent !important
  ② main.tsx：`/pet` 路径时给 <html> 加 `pet-mode` class
  ③ Electron 窗口：transparent:true + backgroundColor:'#00000000' + roundedCorners:false
     + thickFrame:false + setBackgroundColor('#00000000')（双保险）

验证（真屏截图，见 artifacts/v1.84-pet-transparent.jpg）：
  桌面壁纸/网页内容从她周围完整透出，窗口内没有任何底色块。
```

## 二、动作系统（纯 CSS + 状态驱动，占位形象）

| 动作 | 触发 | 表现 |
|---|---|---|
| 待机 | 默认 | 呼吸缩放 + 头轻微摇摆 |
| 眨眼 | 每 3.8~6s 随机 | 眼睛压成线 140ms |
| 眼睛跟随 | 鼠标在窗口内移动 | 瞳孔朝鼠标方向偏移（±2.4px） |
| 被摸 | 单击她 | 挤压回弹 + 头顶爱心飘起 + 眼睛变 ^^ + 腮红加深 |
| 挥手 | 双击她 | 右臂快速摆动 + 气泡"嘿，我在这儿。" |
| 说话 | 气泡可见 | 嘴张开-闭合循环 |
| 走动 | 空闲随机（7~11s 一次） | 左右平移 ±16px + 双脚交替点地 |
| 伸懒腰 | 空闲随机 | 双臂上举（rotate 78°）再放下 |
| 开心 | 她的情绪 top ∈ {joy,love} 且 delta ≥ 0.12 且有气泡 | 跳跃 + ✨ sparkle |
| 打盹 | 低谷中 + 小屋无活动 + 超过 20~25s 没互动 | 眼睛闭成弧 + 头倾斜 + 缓慢呼吸 + Zzz 飘浮 |
| 低落 | 低谷中 | 整体灰蓝配色、嘴下弯、腮红消失 |

另外：`pet-mode` 下隐藏滚动条、整个窗口透明可拖动（顶部 36px 拖动条），按钮/气泡/设置卡都改成半透明玻璃样式，避免遮挡她的动作。

## 三、怎么玩

```
npm run desktop:pet        # 自动起后端 + 打开桌宠
  单击她 = 摸一下（会说话）
  双击她 = 挥手
  聊天   = 打开完整界面
  一眼   = 让她截一次屏（受策略限制）
  设置   = 四种截屏策略
  藏起来 = 关闭窗口
Ctrl+Shift+P（在桌宠窗口内）= 打开聊天
```

## 四、边界

```
· 动作全部是**表现层**，不改她的情绪/状态；情绪→配色/表情是只读映射
· 占位形象是 CSS 画的；换成你设计的 PNG 只需替换 PetApp 里那一块（接口不变）
· 走动只是在窗口内左右踱步（窗口本身不移动，避免乱跑干扰你）
· 透明窗口在 Windows 上不支持点击穿透（她想被摸，所以要可点）
```
