# v2.15 N=3 重复 A/B + unified expression 默认值决定

## 实验设计（避免状态污染）

- 先把线上 `memories/` 复制成**只读快照**（不写线上）；
- **每次运行都从快照重新复制一份 `MEMORIES_DIR`**，用独立端口起隔离 server ⇒ 6 次运行都从同一初始状态开始（不是"跑完 ON 再跑 OFF"的累积状态）；
- 两臂**交替**（on,off,on,off…）以降低时间漂移；
- 禁用语音/活动采样/活动关怀/MCP/提醒等后台副作用，只保留对话主链；
- 每臂 3 次、每次 13 场景 20 轮；结果 `artifacts/v2.14/ab/{on,off}-{1,2,3}.json`。
- 复现：`node node_modules/tsx/dist/cli.mjs scripts/run-ab-repeat.mjs 3`

## 一个必须说明的度量修正

首轮跑完后，OFF 臂 `ask_her_state` 出现过 1 次红：`reply_self_disclosure` 判负。看回复其实是**正确自述**：

> 不太好，说实话。这两天有点往下沉，靠着窗坐了一会儿…心里闷着，提不起劲。

问题在判据：`SELF_DISCLOSURE` 正则要求“我+时间词”，这句话没有“我”字 ⇒ 漏判为“没有自述”。

处理：把判据补上（`(?<!你)这两天/这几天…`、`提不起劲`、`心里闷`、`^不太好`），然后用**新判据对已保存的 6 份运行结果重判**（只改 `reply_self_disclosure` / `reply_self_disclosure_max` 两个 flag，没有重写回复）——重判后六次全 13/13。

这不掩盖事实：**判红是度量 bug，不是回复质量问题**；已在此文档记录。

## 决定：unified expression 默认改为**开**

依据：
1. 3 次全新状态运行，两臂都 13/13，**没有通过率回退**；
2. ON 臂**自我披露少一半**（7.7 vs 16）、“这两天/一直”持续声称少（1 vs 3.7）、字数更短、问号更少——与“表达受限、不抢焦点”的设计一致；
3. 反讽场景可见差异：OFF 会插入“我这两天本来就有点沉”，ON 不插。

代码改动：`src/lib/emotionExpression.ts`

```ts
return env.ENABLE_UNIFIED_EXPRESSION !== 'false';  // v2.15 默认开
```

**回退**：`ENABLE_UNIFIED_EXPRESSION=false`（环境变量/`.env` 均可），旧 `buildUnifiedPermit` 路径仍保留。

风险与诚实说明：

- 这是**启发式判红 + 单机采样**支持的默认值变更，不是人工质量结论；
- 人工复核清单已生成：`artifacts/v2.14/ab/review-sheet.md`（逐场景 ON/OFF 末轮回复 + 空「人工」列），填完回填 `manualVerdict`；
- 模型非确定，均值差不做显著性检验；耗时差异不可当结论；
- 只覆盖 13 场景 20 轮，不代表长期真实使用；后续可按需回退。
