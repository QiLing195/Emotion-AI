# v1.69 正向补偿 A/B · 结论：**不通过，保持默认关**

> 动机（用户问"为什么沉/消极占比大"）：负向三通路叠加、正向只有两路轻推。
> 本刀假设：把 `for_him` 正向 reading 的 calm/love/joy 放大（总量仍受 0.15 上限约束），
> 让她的正向情绪更容易越过死区、出现在话里。
> 开关 `ENABLE_POSITIVE_AMPLIFY`（默认关）｜剧本 6 轮（2 句报喜 + 1 句累）｜3 次/臂 = 18 条/臂。

## 结果

| 指标 | A（关） | B（开） | 判据 |
|---|---|---|---|
| 正向自我表达条数 | 3 | 3 | ❌ ①要求 B≥A+1 |
| 消极自我表达条数 | 0 | **2** | ❌ ②要求不增 |
| 接住他率 | 0.94 | 0.89 | ❌ ③要求不降 |
| 自造外部生活 | 0 | 0 | ✅ ④ |

**三条不通过 ⇒ 保持默认关**（与实验纪律一致；不改阈值凑结果）。

## 怎么解读

```
① n 小（18 条/臂），"消极 0→2"可能有一半是噪声；但**正向表达一条没增**说明
   "放大 appraisal 幅度"这个杠杆**没有把她的话推向正向**（与 v1.47/v1.48 同族的结论：
   描述性/数值性的情绪强度不操纵她的话）。
② 更值得注意的方向：放大正向反而让消极表达出现 —— 一个可能机制是
   calm 被推高后，"平静"这一层在激活态里被压得更低（suppressed），
   她反而更容易注意到"自己底下那点没缓过来的"。
   （这需要专门观测才能定论，本刀不深挖。）
③ 结论：**"正向占比"不是靠调 appraisal 幅度能修的**；它由结构决定（损失厌恶 / 负向三通路 /
   低谷不闭合 / 表达门控）。继续在这条局部杠杆上迭代是浪费。
```

## 因此这条线也收口

```
· ENABLE_POSITIVE_AMPLIFY 保持默认关（代码保留、可回退可观测）
· 不再为"正向占比"做局部幅度调整
· 如果确实要动，只剩三条**结构性**选项（都需要单独预登记 + 风险确认）：
   (a) 损失厌恶设上限/人格参数
   (b) 低谷退出不再只依赖空闲时长
   (c) 表达门控从"低谷×好消息"扩到"任何被激起情绪 × 他问到她"
```
