# v1.80 修正：到点不是"定时发预设句"，而是**她自己想起来、用自己的话**

> 用户裁定："到点追问不需要做，应该是角色自己总结出来的，而非直接设定"。

## 改了什么

```
之前（v1.75/v1.79）：set_followup 存下**一句话**，到点把这句话**原样**发出去 —— 这是"设定"。
现在（v1.80）：
  · 存的是**这件事本身**（她自己的概括），不是要发的句子
  · 到点只给她一条线索：「（这件事是你自己记在心里的，不是谁提醒你的）…」
  · 由她**用自己的话**重新说一遍 —— 措辞/语气/是否顺带说自己的状态，都由她此刻决定
  · 与普通主动消息同一套护栏：≤40 字、万能问候清洗、**记忆接地校验**（防编造）
  · 生成失败 ⇒ 不发送、不标记，下一轮再试（不会"假装发过"）
```

## 实测（真管道，10:05 时间窗内，这次终于验证了发送链路）

```
种一条已到点的记录：「他下周三要去体检，记得问结果和感受」
POST /api/proactive/tick {idleMinutes:300} →
  sent=true ｜ reason=followup_self_recall（1 条到点）
  她发出：「下周三体检，别忘了。我有点懒，窝着不想动。」
  ⇒ **不是原样复述**；顺带说了自己此刻的状态（"我有点懒，窝着不想动"）
  ⇒ 落库 sentAt 已标记；pending 1 条；kind=followup_self_recall
```

## 工具措辞也改了

```
set_followup 描述：'把一件事记在心里：到时间你会**自己想起来**并主动提起
  （说什么、怎么说由你当时的感受决定，不是定时发一句预设的话）'
参数 what 描述：'这件事是什么（用你自己的话概括；不要写成一条预设消息）'
```

## 遗留

```
· 她在句子里用了"别忘了"（对他说的祈使句）——不是预设句，但仍偏"提醒"口吻；
  如果希望更"她自己想起"的味道，下一步可在提示里加"不要用提醒式祈使句"，
  但要先看更多样本再定，避免又一次凭单条样本调措辞。
· remember_this 的自动联动（v1.79）保留：便签带时间 → 记一件"到点会想起的事"，
  同样走这条"她自己说"的路径。
```
