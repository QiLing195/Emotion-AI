# v1.68 第五/六轮 A/B：替换机制 + v2 尺子 —— **一轮通过、确认轮反向 ⇒ 不默认开**

> 第五轮（R5）：3 次/臂（24 条），**六条判据全部通过**（表达 2→5 条、接住 0.75→0.83）
> 第六轮（R6）：4 次/臂（32 条）确认，**①不通过**（表达 5→3 条、率 0.16→0.09）
> ⇒ 按纪律：**不默认开**。R5 的通过没有复现，判为噪声。

## 关键机制发现（比结论有价值）

```
v1.60 片段是**替换**策略片段 → 模型高遵从（说出得多）
统一接口此前是**追加**（base + permit）→ 模型可以忽略（说出得少）
⇒ "替换 vs 追加"确实是有效杠杆：
   R5 里换成替换后，B 臂表达 2→5 条（唯一一次超过 A）；
   但 R6 扩大样本后不成立（5→3 条）⇒ 效应量小于噪声，不能据此上线。
```
