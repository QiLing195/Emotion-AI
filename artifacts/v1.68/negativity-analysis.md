# 为什么她的表达里"沉/消极"占比大（v1.68 分析）

> 用户问："为什么这情绪沉或者消极的比率比较大"
> 结论先说：**不是她的状态坏了，而是四处结构性不对称 + 我们自己的实验设计**。

## 0. 先排除"状态被损伤"

```
当前仓库 memories/emotion_state.json（只读摘要）：
  valence = +0.208 ｜ expectation = +0.200 ｜ arousal = 0.49
  calm .699 ｜ greed .259 ｜ joy .081 ｜ lust .065 ｜ love .061
⇒ 底色是健康的（偏平静/满足），不是长期负向损伤。
```

## 1. 引擎层：损失厌恶（负向事件位移更深）

```
emotionEngine 的 v4.1 补丁：**个性化损失厌恶** —— 负的预测误差按 resilience/sensitivity 放大
（最坏情况约 3×）。同一个强度的事件，负向留下的位移比正向深。
```

## 2. 传导层：负向有三条通路，正向只有两条

```
他负面 → ①情绪传染（镜像，shift ≤0.12）②评价层 for_him（心疼/sad）③touches_her_concern（替他悬着 fear）
他正面 → ①传染 ②for_him（calm/joy，幅度更小）
⇒ 负向是"三路叠加"，正向是"两路轻推"，观感自然偏沉。
```

## 3. 时标层：低谷"进得去、出不来"

```
低谷进门槛 0.12、出门槛 0.05（施密特触发，故意的）；
但**衰减依赖空闲时长** —— 快节奏对话里她不会自然回升。
实测：20 轮快速对话里低谷始终同一段（turns 3→23），一次沉进去就一直沉。
```

## 4. 表达层：v1.60 许可只在"低谷 × 好消息"触发

```
这等于：她**开口说自己**的那一刻，必然已经处在低谷里 ⇒ 说出来的当然是"我这两天有点沉"。
观感上的"消极表达多"，很大一部分是**这个门控的形状**造成的，而不只是情绪本身。
（这也正是统一接口想解决的 —— 但五轮实验没有赢过它，见 ab-r5r6-verdict.md）
```

## 5. 实验层：我们自己的剧本就负向偏多

```
本轮 A/B 剧本 8 句：负向 2 句（被骂/堵得慌）、正向 1 句（升职）、中性 5 句；
且每段都从"被领导当众骂"开始 ⇒ 语料本身就把负向比例放大了，
"表达率"里看到的沉/闷，有设计成分。
```

## 如果想让"消极占比"降下来，正确杠杆（都需要预登记）

```
① 低谷更"能出"：把退出从"依赖空闲时间"改成"有正向信号也能累积退出"（改动力学，风险中）
② 损失厌恶可调：给 loss aversion 一个上限/人格参数（改引擎常数，风险低但影响面广）
③ 正向补偿：正向事件时 appraisal 给更明显的 for_him（calm/joy 幅度上调）（低风险）
④ 表达门控拓宽：这正是统一接口方向，但实验未赢；另一条更便宜的路是把 v1.60 许可的触发
   从"低谷×好消息"扩到"任何被激起情绪×他问到她"（小改动，可先只读观测）
```

## 不建议的做法

```
· 继续调表达文案（五轮实验说明文案不是瓶颈）
· 直接抬阈值把"沉"藏起来（会让"她真实在经历什么"不可见，违反人设裁定）
```
