# v1.71 低谷退出「假设轨迹」模拟（选项 C）· 结论：**纯只读模拟不可行**

> 目的：在不改行为的前提下，用探针日志离线算"如果让 depth 响应正向输入（A）或每轮自然回落（B），
> 她会在第几轮退出低谷"，据此选参数。
> 数据：2 段 20/15 轮真管道（`artifacts/v1.71/probe-seg*.jsonl`，每段 active 18 / 13 轮）
> 脚本：`scripts/simulate-low-exit.ts`（A 的 k 与 B 的 d 各扫 5 档）

## 一、结果（两版模拟，都是负结果）

### 第一版（只做衰减，不模拟负面）：A 一碰就清零
```
A k=0.2/0.3/0.5 → **段内第 1~2 轮就退出**（正向累计一下就把 depth 打到 0）
B d=0.008       → 段内第 8~11 轮退出
⇒ 参数明显过猛/过慢，需要更细的档位
```

### 第二版（加入"负面把她推回去"的现实约束）：**所有改法都永不退出**
```
每一档（A k=0.005~0.05、B d=0.006~0.02）都是"永不退出"，
最低 depth 只到 0.099~0.116（离 0.05 退出线还很远）。
```

## 二、为什么（这一刀真正学到的东西）

```
加入约束后，几乎所有轮次都触发"负面推回"：**真实 depth 始终高于模拟值**。
原因不是"正面不够强"，而是：

  **depth 是内生的** —— 它既是我们想改的那个量，又是这套改法会影响的**下游输出**。
  也就是说：真实日志里的 depth 已经包含了"当前衰减策略"的结果，
  拿它当反事实模拟的输入，等于**用旧策略的结果去预测新策略的行为**。

⇒ 被动日志**在原理上**无法标定这个改动。这不是参数没调好，是**量具不成立**
   （与 v1.45 复盘"复读尺子坏了"、v1.55"理由形状尺子坏了"同一类教训）。
```

## 三、因此下一步只有一条正路（真 A/B，不用模拟）

```
实现开关 ENABLE_LOW_EXIT_DYNAMICS（默认关），两档：
  positive：depth -= k × positiveActivation（k 取 0.03 作为起点，先只跑一档）
  natural ：depth -= d（d 取 0.008）
然后在**真管道**里 A/B：
  臂 A = 现状（depth 只随时间衰减）
  臂 B = 开关开
测什么（预登记，跑之前写死）：
  ① 低谷持续轮次：B 必须显著短于 A（这段语料 A=永不退出，B 应 ≤6 轮）
  ② 退出后不被下一轮负面立刻拉回（稳定 2 轮）
  ③ **v1.60 验收不许退化**：可选表达 ≥5/5、接住 ≥5/5、起因 ≥4/5
  ④ 不得出现"他还在难过，她已经好了"（对负面语料的 5 轮里低谷不许提前退出）
风险：depth 会喂给 v1.60 表达许可的前置条件（earn 门槛），所以 ③④ 是硬门。
```
