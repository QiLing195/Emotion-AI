# Candidate Narrative Strand Separation

Use this skill when a literary candidate spans multiple characters, scene transitions, time points, or narrative evidence layers and may represent more than one event.

## Workflow

1. Break the candidate summary into atomic clauses. For each clause, record the actor, action or state, narrative layer (dialogue, direct narration, reported speech, inner thought, or later consequence), and source page.
2. Compare clauses with the immediately preceding and following candidates. Look for changes in time, location, focal character, cause, response, or information source. A continuous chapter is not enough reason to keep them in one candidate.
3. Split or refocus the record when clauses describe distinct responses or a later consequence that can stand on its own. Do not duplicate the same evidence in two summaries.
4. A PDF page may support multiple candidates only when it contains distinct passages or narrative layers for each. State the boundary clearly and map each summary to its own evidence; page overlap by itself does not make candidates duplicates.
5. Inspect the first and last cited pages and the transition beyond each boundary. Remove adjacent setup or aftermath that does not support the event focus.
6. Synchronize the source batch, progress record, unified index and nested source record, and audit report. When an actual error is corrected, update both project error-ledger files and run the checker.

## Validation

Every clause should map to a specific, distinct source passage. Check that no summary absorbs the next time point or reaction, and that any shared page contains separately identifiable evidence for each candidate.
