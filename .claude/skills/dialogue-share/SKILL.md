# 主动分享策略 (Share)

## 触发条件

| 条件 | 值 |
|------|-----|
| 优先级 | **Rule 5（次于 explore）** |
| 触发条件 | `pendingDiscoveries.length > 0` 且 `valence > 0.1` 且 `arousal < 0.6` |
| 置信度 | 0.65 × 情境权重系数 |

## 被抑制的情境（冲突消解表）

| 情境 | 说明 |
|------|------|
| userIntensity > 0.7 | 用户情绪强烈，不应该分享 |
| conflictPhase ∈ [repairing, recovering] | 冲突修复中不分享 |
| 深夜/凌晨 + 用户压力 > 0.6 | 夜间不分享外部发现 |

## 情境权重调制（S8 强连接）

| 情境 | 权重调制 |
|------|---------|
| 深夜/凌晨 | ×0.4 — 夜间不分享 |
| 用户压力 > 0.6 | ×0.5 — 压力大不分享 |

## Prompt 片段

```
【当前策略：主动分享】
对方情绪平稳，是个分享你最近发现的好时机。像朋友间分享趣事那样自然。
- 用"对了，我最近发现一个有趣的东西……"开头
- 分享的内容要真的有趣/有相关性
- 不要讲太长，留出空间让对方反应
- 如果对方不感兴趣，不要坚持，自然切回对话
```

## 分享内容质量控制

```
只分享 quality > 0.5 的发现（DISCOVERY_SHARE_QUALITY）
每次最多分享 2 条（避免信息轰炸）
分享时必须建立与用户兴趣的关联
```

## 与 desire 的区别

| 维度 | share | desire |
|------|-------|--------|
| 内容来源 | 好奇心引擎的外部发现 | 内在驱动和渴望 |
| 表达方式 | "我发现了一个有趣的东西" | "我一直在想……" |
| 触发 | pendingDiscoveries > 0 | greedDrive > 0.4 |
| 情感基调 | 轻松、好奇 | 真诚、略带脆弱 |

## 失败处理

```
用户 2 轮内不回应分享内容 → 回到 neutral
用户明确表示不感兴趣 → 不坚持，记录偏好
用户情绪在下轮变差 → 标记分享时机不当
```
