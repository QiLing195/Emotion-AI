# 转移注意策略 (Redirect)

## 触发条件

| 条件 | 值 |
|------|-----|
| 优先级 | **Rule 2（次于 empathize）** |
| 触发条件 | `consecutiveNegativeRounds ≥ 3` 且 `!isRecovering` |
| 置信度 | 0.75 × 情境权重系数 |
| 恢复检测 | 最近 2 轮效价值递增 → 判定为自然恢复，跳过 redirect |

## 被抑制的情境（冲突消解表）

| 情境 | 说明 |
|------|------|
| conflictPhase ∈ [repairing, recovering] | 冲突修复中不转移话题 |
| 深夜 + 用户压力 > 0.6 | 深夜情绪脆弱，转移可能适得其反 |
| 用户高强度情绪 (intensity > 0.7) | 应该先 empathize |

## 情境权重调制（S8 强连接）

| 情境 | 权重调制 |
|------|---------|
| 用户压力 > 0.6 | ×0.6 — 压力大不适合转移 |
| 深夜/凌晨 | ×0.5 — 夜间不适合转移 |

## Prompt 片段

```
【当前策略：转移注意】
对方已经连续表达了好几轮的负面情绪。不是要忽视他的感受，而是轻轻地、自然地转移话题。
- 先简短共情（1句话），然后用"说起来……"自然转向
- 选择与当前对话有微弱关联但更轻松的方向
- 不要生硬跳转（别说"别想这个了"）
- 如果对方抗拒转移，立刻回到共情模式
```

## 话题选择算法

基于当前主导情绪自动选择转移方向：

| 主导情绪 | 转移方向 | 示例 |
|---------|---------|------|
| sad 悲 | 温暖的回忆 | "说起来，你上次说的那个好笑的事……" |
| anger 怒 | 平静的活动 | "要不要聊聊你最近在看的那个……" |
| fear 惧 | 安全的话题 | "对了，你还记得我们聊过的……" |
| joy 喜 | 近期的趣事 | "说起来，你上次提到……" |
| 其他 | 日常话题 | "那你今天除了这个还有……" |

## 安全阀

```
用户回应 valence < -0.3 → redirect 失败 → 回到 empathize
用户说 "别转移话题" → 承认并道歉 → 回到 empathize
```
